# Generating Candidates

How to produce names worth checking. The difficulty is specific: a name a model offers confidently sits where other people's models also land. The obvious, fitting name for a category is the one many people asked for and many models gave, so it is the likeliest to be taken or about to be. Generation here works against that pull.

The controls below are leads and not proven fixes. Evidence that any method moves a model off the common names is thin, so the result flags convergence and the checks decide.

## Before Generating

- Settle the goal, including its taste item: what the person has liked and rejected and why, and anything the name must contain. One reaction, such as a name that sounds like the wrong kind of brand, steers better than any amount of description
- Let the goal decide the kinds of name to make. A product wants names that could carry a brand. A domain only wants short, typeable ones. A handle wants what fits the platform. A name with no market can be plain and descriptive
- Ask whether the name should explain itself or be given its meaning by the product, because a name of the other kind rarely satisfies
- Put the name in use now in the set. It is checked like the rest

## Where Names Come From

Draw on many methods and many sources, and spend a share of the set away from where the first ideas landed:

- **Ordinary word formation:** Compounds of two plain roots, blends of two words, clipped or truncated words, affixed roots, acronyms and initialisms, and phrases of several words
- **Real words that are rare or old:** Dictionary entries, archaic and technical vocabulary, and words from another language of the market, each checked for its dictionary sense, its sound-alikes, and the price of its domain
- **Roots and origins:** Etymons of the product's own words in other languages, and the same idea one language over
- **Invented words:** Coinages built from a recognizable root, and names built from sound alone, shaped by what sounds suggest, such as the speed, size, or warmth that certain sounds and endings tend to carry. Word builders for constructed languages produce invented words with a consistent sound
- **Respellings:** A real or invented word spelled another way. Generating them is allowed. Guessing how a stranger would type a name is not evidence and adds no spelling to the search
- **A different direction:** Names that fit another reading of the goal, such as a broader or a narrower scope than the one stated, so the set is not all the same idea. Say plainly which names do this
- **The product's own specifics:** What it does that others do not, the moment it is used, the object or gesture at its center. Category words such as the field's name and its obvious verbs are the crowded ones

Cover any form of name the goal can use: one word, several words, acronyms, invented words, and respellings. Spread across them until the person has said which they want.

## Catching Convergence

- **Generate in separate passes.** Run several passes that do not see each other's output, in fresh sessions or through helpers, or without either one after another, each starting from the goal and not from an earlier list, and let each pass use different methods and sources from the list above. A pass that starts from the previous list will drift to it
- **Flag a name that comes back.** When several passes, or several models, produce the same name, the result flags it as convergent. A recent registration of that name, such as a domain, a repository, a handle, or a mark created in the last months, is read as a sign someone else's model got there first
- **Never remove a name for converging.** The flag is evidence about where the name sits, and the checks weigh what is actually there. A convergent name is still checked in full
- **A second model family is an option.** Another model family may generate in separate passes when the person turns it on. It is not the default. Reach one through the harness's spawn guidance
- **Do not present a confident name as a find.** Confidence is a sign of crowding, not of quality

## What To Present

- A name shown to the person has been checked. Present it with its result and its address and price, so a name can be registered the moment it is chosen
- A draft discarded before anyone is shown was never in play. Discard for fit to the goal and the person's stated taste, never because a name is off-direction or of a different scope, which the goal allows on purpose, never on a guess that a name is taken, and never on one lookup that does not remove it by the early-removal rule
- Generate a set that can be checked in full over one that cannot. When the person asks for a large set, generate it, then check all of it, removing a name early only for an observed reason that is listed

## When A Loved Name Is Taken

A person usually recognizes the feel they want before any name clears. When a name they love comes back Avoid, do not go back to a blank page. Generate its neighbors: the same root with another ending, the same rhythm, the same idea one step over. Check them before showing them. A neighbor keeps the feel the person already chose, so try neighbors before a fresh list.

## Rounds

Names are found by reacting, not by one large list. After each round ask which names the person would say aloud and which they would not, and why, then generate the next round around those reactions, still in separate passes. Keep every checked result from earlier rounds in the ranking, so nothing is checked twice and a name that returns is recognized.

Stop when the person has a name they are happy to say aloud and whose result, a Clean, a Fine, or a Caution with its size and open question, they accept. When the name in use is among the best after real rounds, say so plainly. Keeping it is a result.

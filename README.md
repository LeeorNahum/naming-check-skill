# naming-check-skill

`naming-check` evaluates a proposed brand, product, company, app, or domain name for conflicts, risks, and quality.

It closes with one verdict: Clean, Caution, or Avoid.

## Files

- `SKILL.md` contains the checklist and output format.
- `AGENTS.md` is the maintenance contract for editing this skill.

## Install

```bash
git submodule add https://github.com/LeeorNahum/naming-check-skill.git .agents/skills/naming-check
```

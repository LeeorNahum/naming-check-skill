# Naming Check

Evaluate a proposed name across these dimensions, then give a clear verdict.

## Checklist

**Conflicts & legal**
- Search for existing brands, products, companies, apps using the exact name and close variants
- Check for trademark registrations (search USPTO, EUIPO, or equivalent; note if a full TM search is advisable)
- Note any large, aggressive trademark holders whose name it starts with or closely resembles

**Domain & handles**
- Check if `.com` is available (primary signal); note `.io`, `.app`, `.co` as fallbacks
- Note if social handles are likely taken (don't enumerate all — just flag if it's a common word)

**Linguistic & cultural**
- Does it have unintended meanings in major languages (Spanish, French, German, Italian, Portuguese, Japanese)?
- Any negative, embarrassing, or offensive associations?
- Does it derive from or closely resemble a word in another language — note it (could be a positive or a risk)

**Pronunciation & clarity**
- Is it phonetically unambiguous? List likely mispronunciations if not
- Does it read naturally in writing without needing explanation?

**Brand quality**
- Is the meaning/portmanteau immediately clear or does it need a tagline?
- Memorable? Distinctive? Easy to spell from hearing it?
- Any accidental double-meanings or unfortunate abbreviations?

## Output format

Lead with the verdict: **Clean**, **Caution**, or **Avoid** — then one short paragraph of key findings, then a bullet list of specific risks or positives worth noting. Keep it concise.
